## OpenClipboard untuk macOS sebelum Liquid Glass

Versi ini menurunkan target minimum ke **macOS 13 Ventura** di Mac Apple Silicon. Popup dan panel bawah memakai latar buram di Ventura, Sonoma, dan Sequoia. Liquid Glass tersedia mulai macOS 26.

Perekaman clipboard dan perpindahan fokus kini menyesuaikan API yang tersedia di masing-masing versi macOS.

Kedua tampilan buram berhasil dibuka dengan build uji di macOS 27. Pengujian langsung di macOS 13–15 belum dilakukan saat rilis ini terbit. [Panduan pemasangan](https://github.com/ryan-prayoga/OpenClipboard#unduh-dan-pasang)
