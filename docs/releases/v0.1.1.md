## Dukungan macOS 26

Versi ini menurunkan syarat minimum dari macOS 27 ke **macOS 26** untuk Mac Apple Silicon. Popup dan panel bawah tetap memakai Liquid Glass. Efek kaca interaktif yang memerlukan API macOS 27 tersedia di versi tersebut dan yang lebih baru.

Build diperiksa dengan SDK macOS 26.5 dan berhasil dibuka di macOS 27.2.1. Pengujian langsung di macOS 26 belum dilakukan saat rilis ini terbit. [Panduan pemasangan](https://github.com/ryan-prayoga/OpenClipboard#unduh-dan-pasang)
